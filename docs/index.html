      02 — Verifying what you installed

      A checksum says it arrived intact. An attestation says who built it.

      Builds carry a GitHub attestation, so the binary Scoop downloaded can be traced back to the commit and the workflow run that produced it.

      gh attestation verify (scoop prefix wymcmd | Join-Path -ChildPath wymcmd.exe) --owner Talkdedsec

      excavator runs every day.

      It notices a new release upstream, updates the manifest and commits it. Nothing here is updated by hand unless the shape of a release changes.

      03 — Reporting a problem

      A bug in a tool belongs in that tool’s repository. Open an issue here only when the packaging is what is wrong:

      • a manifest that installs the wrong architecture
      • a shim that does not appear on PATH
      • a hash that no longer matches
